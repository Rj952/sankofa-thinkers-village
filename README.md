# Sankofa Thinkers' Village

An illustrated, animated journey through philosophy for doctoral and advanced learners: from the wisdom teachings of ancient Kemet, through the Agora, the scholars of Timbuktu and Córdoba, the Enlightenment, the industrial age and critical theory, across the Pan-African bridge to the Caribbean shore, ending at the Algorithm Lighthouse.

73 houses · 10 chapters · 6 threads. Policy case files, error reporting, review status, read-aloud, lite mode and offline use. Cinematic opening, parallax scenes, a fly-through mode for presenting, a Compare tool that generates debate prompts for any two thinkers, and a full APA 7 sources section at the end. Each house offers the idea, key concepts, an educational lens, a policy lens, three critical questions, a reflection prompt, sources, links to related thinkers, and a slot for your own video.

Designed by Dr. Rohan Jowallah, Ed.D., FHEA.

## Publish on GitHub Pages
1. Create a new public repository (for example `thinkers-village`) under your GitHub account.
2. Upload `index.html`, `media.js` and this `README.md` to the root of the repository.
3. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, branch `main`, folder `/ (root)`, and save.
4. After a minute the site is live at `https://<your-username>.github.io/thinkers-village/`.

## Add your videos and narration
Open `media.js` and paste a YouTube link next to any thinker id or district. Thinker ids appear inside each house (for example `id: freire`). District ids: `nile, agora, crossroads, harbour, square, quarter, bridge, shore, light`.
For narration, add an `audio` folder with MP3 files and list them under `audio`.

## Deep links
Link straight to a house with its id, for example `.../#freire` or `.../#garvey`.

## Privacy
Progress and reflections stay in each learner's own browser. Nothing is collected or sent anywhere.
