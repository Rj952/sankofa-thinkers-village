For facilitators

Using the village

The village works as a self-paced journey, a seminar launch pad, or a debate map. Suggested uses:

  • Before a seminar: assign a district; each participant brings one critical question answered in writing.
  • Thread debates: pick a thread, assign two thinkers from different districts, and stage a dialogue between them.
  • Policy clinic: use the policy lens of three thinkers to critique a live national or regional policy.
  • Paired debates: open Compare, choose two thinkers from different chapters and use the generated debate prompts.
  • Presenting live: “Play the fly-through” moves the camera slowly through every chapter, pausing on each title card.
  • Capstone: the Algorithm Lighthouse asks learners to build their own framework from at least three districts.

Adding your videos

Edit media.js in the repository. Use a thinker's id (shown below each house title) or district: plus a district id:

window.VILLAGE_MEDIA = {
  videos: {
    "freire": "https://youtu.be/YOUR_ID",
    "district:shore": "https://youtu.be/YOUR_ID"
  },
  audio: {
    "garvey": "audio/garvey.mp3"
  }
};

YouTube links play inside the page on GitHub Pages. Other links open in a new tab. You can also test a link on one device using “Add a video link” inside any house.
